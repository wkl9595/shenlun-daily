System Architecture

Daily pipeline: RSS → AI processing → static site → WeChat push

Pipeline Overview

📡 RSS Feeds
→
🤖 CLI Script
→
🧠 OpenAI
→
📄 Markdown
→
📱 WeChat
Phase 1 — Fetch
• Cron triggers daily at 8am
• Read RSS feeds: 人民日报, 新华日报, 求是, etc.
• Compare with already-fetched URLs
• Deduplicate & filter to last 24h
Phase 2 — Classify
• Send article to OpenAI GPT-4o-mini
• Match against preset categories
• Suggest new sub-categories if needed
• Extract 3-5 key sentences per article
Phase 3 — Generate
• Write markdown to content/
• Generate category index pages
• Build daily digest markdown
• Commit + push to git repo
Phase 4 — Deliver
• Vercel auto-deploys on push
• Send WeChat bot message
• Summary: "今日收录X篇文章，分类Y个主题"
• Link to daily digest page

Key Design Decisions

No database Markdown files + frontmatter = all storage. Git history = audit trail.
No API server VitePress SSG generates the entire site at build time. No runtime.
OpenAI gpt-4o-mini Cheap & fast for classification + extraction. ~$0.01/day of article processing.
WeChat Webhook Simple POST to bot webhook with markdown-formatted digest.
